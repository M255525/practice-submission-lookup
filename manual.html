課堂練習存摺｜使用說明

適用課程：跨境電子商務

同學怎麼查

  1. 打開查詢頁，輸入自己的學號，按「查詢」。
  2. 畫面會列出老師已登錄的每一筆練習：工具名稱、練習主題、練習數量、產出日期、上課批次。
  3. 姓名只顯示首尾字（例如「林*妤」），用來確認是自己的資料。
  4. 上方的 KPI 卡片：繳交率（已登錄場次 ÷ 全班上課場次）、工具完成、練習數量 PR 值（和已登錄同學比較，76 代表勝過約 76% 同學）、連續繳交場次；有缺交的場次會列出日期與工具。

繳交分析

  • 每張 KPI 卡片右上有 ⓘ：滑鼠移上去（手機點一下）會浮現這個數字的算法說明。
  • 切換到「繳交分析」不用輸入學號，會顯示全班彙總：已登錄學員、上課場次、平均繳交率、全勤人數、累計數量。
  • 圖表包含各場次繳交率、每人繳交幾場的分布、各組繳交率。滑鼠移到長條上可看詳細數字。
  • 只顯示彙總數字，不含任何姓名或學號。場次以 LINE 記事本名稱的日期判斷；「候補」之類的名稱會依工具歸入對應場次。從未繳交過的同學不在資料中，不計入分母。

組別查詢

  • 切換到「組別查詢」，輸入自己的學號，就會列出你所屬組別的全部組員。
  • 只看得到自己那一組：組別依你已登錄的練習紀錄判斷，還沒有任何紀錄（或紀錄沒寫組別）就查不到。
  • 每位組員只顯示遮罩後的姓名、系所、部分學號，以及各練習工具的累計數量；不顯示練習主題與日期。

常用設定（右上角 ⚙）

  • 記住我的學號：預設開啟，下次打開會自動帶入學號。在電腦教室或共用電腦上請關閉。
  • 開啟頁面時自動查詢：記住學號後可開啟，打開網頁就直接顯示自己的紀錄。
  • 字體大小：標準／大／特大，手機或投影時好閱讀。
  • 清除本機資料：刪除這台裝置記住的學號與設定。
  • 右上角「📲 加入主畫面」可把查詢頁放到手機桌面，像 App 一樣打開。

查不到或資料有誤怎麼辦

  • 練習證明上傳到 LINE 記事本後，需要老師整理、辨識後才會出現，不是即時更新。
  • 圖片模糊、被裁切，或證明上的學號填錯，都可能導致查不到。
  • 依課程規範，有問題請於上課期間主動向老師反映，課後才提出原則上不予補登。

老師維護說明

  • 資料來自試算表「上傳檔案分類」的「辨識結果」分頁（由 line-notebook-ocr 寫入），直接改試算表即可，網頁不需重新部署。
  • 查無資料時顯示的規範文字，讀自同一份試算表的「說明」分頁 A 欄。
  • 查詢 API 只回傳學號完全相符的資料，不回傳原始 OCR 全文、圖片連結與完整姓名；試算表本身不需要、也不應該開放分享。
